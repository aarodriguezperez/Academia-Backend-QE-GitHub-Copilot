# Semana 03 - Core Avanzado, Seguridad, WebFlux y Unit Testing

Durante esta semana se trabajaron conceptos avanzados de Java y desarrollo backend, incluyendo manejo de archivos, serialización, seguridad, programación reactiva y pruebas unitarias.

---

## Proyectos

### [01 - Core Avanzado](./01-core-avanzado/)

Manejo de archivos y serialización en Java.

También se documenta el concepto de threading, aunque no se desarrolló un proyecto específico de hilos.

### [02 - Spring Security](./02-spring-security/)

Implementación y comparación de diferentes mecanismos de seguridad:

- HTTP Basic
- JWT
- OAuth2
- BCrypt

### [03 - WebFlux](./03-webflux/)

Introducción a programación reactiva utilizando:

- `Mono`
- `Flux`
- Spring WebFlux
- Comparación entre código reactivo y bloqueante

### [04 - Unit Testing](./04-unit-testing/)

Pruebas unitarias utilizando:

- JUnit
- Mockito
- `@BeforeEach`
- `assertThrows`
- `@Mock`
- `@InjectMocks`
- `when`
- `verify`

---

> La explicación detallada y los ejemplos utilizados se encuentran en el README de cada proyecto.
