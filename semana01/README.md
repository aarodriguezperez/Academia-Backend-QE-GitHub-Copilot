# Semana 01 - Fundamentos de Java y POO

Durante la primera semana se trabajaron los fundamentos de **Java** y **Programación Orientada a Objetos (POO)** mediante el desarrollo de un proyecto práctico.

El objetivo fue aplicar conceptos como clases, objetos, herencia, polimorfismo, interfaces y encapsulación, además de utilizar herramientas del lenguaje como generics, expresiones lambda, `Comparable`, `Comparator` y manejo de excepciones.

---

## Proyecto

### [01 - Fundamentos de Java y POO](./01-fundamentos-java-poo/)

Proyecto práctico basado en un **Taller Automotriz**, donde se modelan vehículos, clientes, mecánicos, servicios, refacciones y órdenes.

El proyecto permite aplicar diferentes conceptos de Java y Programación Orientada a Objetos dentro de un mismo escenario.

### Principales conceptos trabajados

- Clases y objetos
- Clases abstractas
- Herencia
- Encapsulación
- Interfaces
- Polimorfismo
- Relaciones `IS-A` y `HAS-A`
- Upcasting y Downcasting
- Strategy
- Singleton
- Generics
- Comparable y Comparator
- Expresiones Lambda
- `static` y `final`
- Constructores
- Getters y Setters
- Manejo de excepciones
- Modificadores de acceso
- `@Override`

> La explicación detallada de dónde y cómo se utiliza cada concepto se encuentra en el README del proyecto.
