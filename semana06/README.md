# Semana 06 - GitHub Copilot

Durante esta semana se trabajó con GitHub Copilot sobre el proyecto TaskFlow,
utilizando GitHub Copilot CLI, VS Code, MCP, skills, agentes personalizados,
Code Review y un proyecto final.

El trabajo completo se encuentra en un repositorio independiente:

## Repositorio de la semana

[taskflow-copilot-aarodriguezperez](https://github.com/aarodriguezperez/taskflow-copilot-aarodriguezperez)

- GitHub Copilot CLI
- Especificaciones y revisión de código
- Model Context Protocol (MCP)
- Servidor MCP propio en Java
- Skills y agentes personalizados
- Integración con VS Code
- Proyecto final: `GET /reports/progress`
