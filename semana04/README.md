# Semana 04 - React y TaskFlow

Durante esta semana se trabajó en el desarrollo de una aplicación frontend utilizando **React y TypeScript**.

El proyecto principal fue **TaskFlow**, una aplicación desarrollada en un repositorio independiente debido a que cuenta con su propia estructura, configuración y flujo de despliegue.

---

## Proyecto

### TaskFlow

Proyecto desarrollado con:

- React
- TypeScript
- Vite
- Material UI
- React Router
- Consumo de API REST
- Autenticación mediante JWT

El proyecto incluye funcionalidades relacionadas con la gestión de proyectos y tareas.

El código fuente y la documentación se encuentran en el siguiente repositorio:

[Ver repositorio TaskFlow](https://github.com/aarodriguezperez/TaskFlow)
